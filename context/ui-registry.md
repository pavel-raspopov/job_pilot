# UI Registry

Living document. Updated after every component is built. Read this before building any new component — match existing patterns exactly before inventing new ones.

---

## How to Use

Before building any component:

1. Check if a similar component already exists here
2. If yes — match its exact classes
3. If no — build it following ui-rules.md and ui-tokens.md, then add it here

After building any component — update this file with the component name, file path, and exact classes used.

## Async action buttons

Any button that fires a request disables itself while in flight and swaps its label to a present-participle form with an ellipsis ("Uploading…", "Extracting…", "Saving…"). Add `disabled:opacity-60 disabled:cursor-not-allowed`. Never show a spinner-only state — the label carries the meaning.

## Button Standard

All buttons use `rounded-md` (8px) and `px-4 py-2` padding per ui-tokens.md / ui-rules.md. Do not use `rounded-lg` or larger custom padding on buttons.

## Card Standard

All content panels use the **Card (surface)** pattern above: `bg-surface border border-border rounded-2xl p-6 shadow-card`. Elevation is `shadow-card` — never inline arbitrary shadow classes. `rounded-2xl` for cards, `rounded-md` for controls.

Two documented padding overrides exist. Do not add a third without recording it here:

- **Filter toolbar** (`JobFilters`) uses `p-4` — a single row of controls with no field labels, which `p-6` makes noticeably taller than the design.
- **Table card** (the jobs list) carries **no card padding at all** — the cells' own `px-6 py-4` provides it, and the header row, row dividers, and footer `border-t` must all reach the card's edges.

## Focus State Standard

Interactive controls use `focus:outline-none focus:ring-1 focus:ring-accent` (1px accent ring). Do not use `ring-2` or non-accent ring colors.

## Font Standard

Only Inter is used throughout, imported via `next/font/google` in the root layout. No secondary display fonts (e.g. Playfair Display) — use font-weight and italic styling for emphasis instead.
