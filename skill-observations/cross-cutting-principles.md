# Cross-Cutting Principles

Active principles that apply across skills.

Apply at each skill's next update unless marked for immediate propagation.

---

### Principle: Skill-readable artifacts

**Status:** ACTIVE (opportunistic)
**Approved:** 2026-08-11
**Source:** Observation 2 (chatbot-builder); adopted 2026-08-18

**Principle:** Durable guidance must be written in the formats each consuming skill expects to read. Ad-hoc notes do not substitute for a skill's required structure (tables, baselines, sidecars, frontmatter).

**Applies when:** Creating or updating skills that write or consume project docs (registries, DESIGN.md, OpenSpec artifacts, memory).
